# Crossmedia Projekt

**Projekt, Crossmedia: Projekt, Malmö Universitet, Vårterminen 2026**

## Beskrivning

Det här projektet är en webbsida med funktion att "chatta" enligt ett manus som används i kursen *Crossmedia: Projekt* för vårt spel. Websdian är uppbygg i HTML, CSS & JS. Webbsidan är hostad på GitHub Pages, därför behövs inga externa tjänster. Spelets gång lyder: efter startat spel kan användaren skicka meddelanden med dom 2 olika karaktärerna Anna och Bodil. Den finns kodinmatning för 4 olika koder som man låser upp genom spelets gång. Efter att ha skrivit in alla 4 koder, kommer användaren till spelets avslut där man gör ett val mellan 3 olika alternativ som ger en olika slut beroende på vad man väljer. Spelet kan ej spelas enbart över internet utan spelas delvist fysiskt för olika ledtrådar man låser upp.
